判讀邏輯與資料來源說明

本頁紅／綠顏色邏輯與 pandatracing 一致：對風險資產（美股、台股、加密貨幣）而言，🔴 代表偏熱／偏鷹（升息或高利率壓力，偏利空）、🟢 代表溫和降溫／偏鴿（偏利多）、🟡 代表中性；市場漲跌幅統計表則維持 綠漲、紅跌。

實際值由 GitHub Actions 每日更新（daily.yml），取自免 API Key 公開來源：FRED、BLS API v1、美國財政部、DBnomics BEA、美國普查局 Census、TradingEconomics 與 Yahoo Finance（yfinance CBOT ZQ 期貨與匯率商品快照）；歷史市場反應使用本站 data 分支 history_1d.json.gz 約 10 年日線計算。

預期值僅於具有可靠公開出處（TradingEconomics、Investing.com、WSJ、路透／道瓊調查、CME FedWatch）時顯示；無可靠來源者一律標示「無可靠預期值」，並改用「高於／低於前值」進行比較與統計。

利率（3） 通膨（5） 就業（5） 成長（4）

利率（3 項）

聯邦基金利率目標區間與 2 年期／10 年期美債殖利率，決定全市場無風險資金成本與估值折現率。

通膨（5 項）

CPI、核心 CPI、PCE、核心 PCE 與 PPI；走勢圖顯示近 24 個月環比 %，數字越接近 0 代表漲勢越收斂。

就業（5 項）

非農就業新增、失業率、平均時薪、每週初領失業金人數與 JOLTS 職位空缺；高利率環境關注就業是否「有序降溫」。

成長（4 項）

GDP 年化季增率、ISM 製造業／服務業 PMI 與零售銷售，衡量美國內需動能與景氣溫度。
