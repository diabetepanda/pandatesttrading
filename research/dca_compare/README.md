# 「定期定額」與「單筆買進抱著」vs. 網站上線六種策略比較研究 (`research/dca_compare`)

本目錄針對五大核心標的（**台股加權指數 `^TWII`**、**`S&P 500`**、**`Nasdaq 100`**、**`黃金 (XAUUSD)`**、**`比特幣 (BTCUSDT)`**），在**同一段期間、同樣的總投入金額（$100,000）**下，公平比較被動買進持有、定期定額（含每週／每月頻率與跌深加碼版）、Signal Desk 現有六種策略（`L1`、`L2`、`L3`、`L4`、`S2`、`S3` 及 `F4` 對照）以及「一半定期定額＋一半最佳策略」混合方案。

## 檔案結構

- `run_dca_compare.py`：完整回測、滾動視窗檢驗（3 年與 5 年持有期）與報告自動生成腳本。
- `report.md`：白話實證研究報告（開頭一句話結論、五大標的與組合總表、公平性與資金效率拆解、2020/03 與 2022 股災表現、滾動測試中位數與最差情況、操作負擔與「適合誰」指南）。
- `results.json`：機器可讀的完整回測數據與滾動統計指標。
- `cache/`：本地離線快取目錄（已加入 `.gitignore`，不納入版控）。

## 比較方案一覽（總投入本金皆為 $100,000）

1. **定期定額（`DCA_Monthly` / `DCA_Weekly`）**：
   - 每月固定日（每月第 1 個交易日）或每週固定日（每週第 1 個交易日）投入固定金額，檢驗扣款頻率差異。
2. **單筆買進抱著（`Lump_Sum`）**：
   - 期初第 1 個交易日一次投入全部 $100,000 買進並持有至期末。
3. **定期定額加碼版（`DCA_Dip_2x` / `DCA_Dip_PoolCap`）**：
   - 每月固定日扣款，當扣款日收盤價 **低於 200 日均線（`< SMA200`）** 或 **距離歷史已發生高點回落超過 20%（`≤ 0.80 × RunningPeak`）** 時，當月投入金額加倍（$2\times$）。嚴格僅使用當下及過去歷史資料（無未來函數），且不加槓桿。
4. **現在上線的六種策略（`L1`、`L2`、`L3`、`L4`、`S2`、`S3`，另附 `F4` 對照）**：
   - 沿用 `src/strategies/six_strategies.py` 回測引擎與參數，以及 `config/config.yaml` 既有交易成本（手續費、點差、滑價與隔夜融資費率），**每筆停損風險設定為 `0.75%`**，換算為 $100,000 起始資金之每日市值（Mark-to-Market）權益曲線。
   - 同時評估「單一標的子帳戶」「五標的共用子帳戶」與「網站全商品池（16～42 檔）子帳戶」。
5. **最佳策略 ＋ 定期定額混合（`Hybrid_50DCA_50L4` / `Hybrid_50DCA_50L2`）**：
   - 一半資金（$50,000）做每月定期定額，一半資金（$50,000）跑六策略中表現最穩健的 `L4（主流週線趨勢）` 或 `L2（精簡趨勢跟隨）`。

## 公平性與防自欺設計

- **資金加權年化報酬（XIRR）vs. 複合年化成長率（CAGR）**：定期定額資金是分批進場（平均在場時間僅約全期的 50%），因此採用精確對齊每筆現金流日期的 **XIRR（內部報酬率）** 作為主年化指標，並同時列出以 $100,000 總資金池起算的 **Pool CAGR** 供雙重對照。
- **統一分母的最大回撤與水下天數**：以 $100,000 總資金池每日市值權益曲線計算高點回落最大回撤（`max_dd_pool_pct`）與未創高水下日曆天數（`underwater_peak_days`），並額外提供帳面市值低於累積已投入本金的最大虧損比例（`max_dd_cost_pct`）與賠本金天數（`underwater_cost_days`）。
- **多起點滾動測試（Rolling Windows）**：以歷史上每一個月的第一個交易日作為獨立起點，分別測試持有滿 **3 年（36 個月）** 與 **5 年（60 個月）**，完整報告所有梯次的**中位數（Median）**與**最差情況（Worst Case）**。
