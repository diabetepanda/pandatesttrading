# 歷史高點下跌回本區間統計與高點進場全天候投資策略研究 (`research/peak_recovery`)

本研究針對一般上班族最常擔心的兩個實戰問題進行完整歷史回測與 5,000 次區塊重抽樣（Block Bootstrap）壓力測試：

1. **Q1（高點套牢要多久才回本？）**：當股市創歷史新高後開始下跌，依最大跌幅分級（`10%～20%` 修正、`20%～30%` 熊市、`30%～50%` 大熊市、`50%` 以上崩盤），下跌期、回升期與總水下期各要幾個月？「不含息價格指數」與「含息再投資總報酬」、「美元計價」與「台幣計價」差多少？
2. **Q2（如果最倒楣買在最高點，哪種方法最適合一般上班族？）**：每月第一個交易日固定投入 `10,000` 台幣（對照組 `M1` 為 120 萬一次單筆買進），比較 **M1～M8（共 12 種配置與策略變化）** 在歷史股災最高點進場、全歷史滾動 10 年，以及未來 10 年「上漲（`>7%`）、盤整（`0%～7%`）、下跌（`<0%`）」三種行情下的年化報酬（XIRR）、最大回撤、10 年虧錢機率與回本月數，並依風險承受度（`-30%` 保守型、`-50%` 一般型、`-60%` 積極型）給出具體推薦。

## 資料涵蓋範圍與清洗規格

- **直接重用既有快取與清洗邏輯**（與 `research/dca_allocation_grid` 完全一致）：
  - 台股：`^TWII`（1997-07-02 起價格指數）、`0050`（含息還原；修正 2025 拆股斷層與 2009–2014 配息，2009-03-10 前以 `^TWII + 3%/年` 估計股息模擬）、`00631L`（2015-08-25 前以 `2 × 0050 - 1.16%` 總費用率模擬）。
  - 美股：`SPY`（1993 起）、`QQQ`（1999 起）、`TQQQ`（2010-02 前以 `3 × QQQ - 0.88% 費率 - 2 × ^IRX` 模擬），美股配息均扣除台灣投資人 `30%` 預扣稅。
  - 匯率與利率：`TWD=X`（清除錯價跳點；真實日線自 2004-03-24 起，更早期間延用 `32.02`）、`^IRX`（美國 13 週國庫券殖利率，用於槓桿融資、閒置現金生息與 `M8` 美國短債累積報酬）。
- **新增長歷史指數快取**：
  - `^GSPC`（S&P 500 價格指數，1927-12-30 起，涵蓋 1929 大蕭條與 1973 石油危機）
  - `^SP500TR`（S&P 500 含息總報酬指數，1988-01-04 起）
  - `^NDX`（Nasdaq 100 價格指數，1985-10-01 起）
  - `^IXIC`（Nasdaq 綜合價格指數，1971-02-05 起）

## 檔案清單

- `run_peak_recovery.py`：獨立可執行的完整研究主程式（含快取重用、缺漏指數下載、異常值檢查、水下期分級統計、M1～M8 回測、記憶體友善分批 Block Bootstrap、三項獨立交叉驗證與 PNG 圖表產出）。
- `results.json`：結構化研究結果（最上層欄位：`meta`、`data_sources`、`data_issues`、`episodes`、`episode_summary`、`peak_start_tests`、`rolling_10y_by_regime`、`bootstrap_10y_by_regime`、`ranking`、`recommendations`；所有數值保留 2 位小數，檔案小於 5 MB）。
- `report.md`：白話繁體中文完整研究報告（含一句話總結、Q1 白話總表與最長 5 大股災故事、Q2 三種行情對照表、高點進場實例表、三種投資人推薦與研究限制）。
- `underwater_duration_bars.png`：各主要歷史事件總水下月數長條圖（依跌幅分色，對照價格版 vs 含息版）。
- `regime_xirr_boxplots.png`：各方法在上漲、盤整、下跌三種 10 年行情下的 XIRR 箱形圖。
- `peak_2000_2008_equity_curves.png`：2000 年與 2007/2008 年最高點進場之 10 年帳戶市值曲線對比圖。
- `test_peak_recovery.py`：獨立驗證測試套件（手算事件比對、已知歷史事件錨點驗證、逐日股數獨立重算誤差 `< 0.01%` 與 JSON 結構檢查）。
- `cache/`：本地資料快取目錄（已列入 `.gitignore`，不納入版控）。

## 執行方式

1. **使用本地快取離線重跑完整研究並產出 `results.json` 與三張 PNG 圖表**（針對 8 GB Mac 採分批運算，峰值記憶體低於 300 MB）：

```bash
.venv/bin/python research/peak_recovery/run_peak_recovery.py
```

2. **強制重新自 Yahoo Finance 下載最新資料並更新快取後執行**：

```bash
.venv/bin/python research/peak_recovery/run_peak_recovery.py --refresh
```

3. **執行本研究與全專案測試套件**：

```bash
.venv/bin/pytest research/peak_recovery/test_peak_recovery.py tests/
```
