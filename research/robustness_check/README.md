## 一、如何重跑本研究

所有運算均優先重用本地快取，無須 API Key 或外部權限：

1. **完整執行八關驗證並產出 `results.json` 與 4 張高解析度 PNG 圖表**（每種 Bootstrap 跑滿 `5,000` 條路徑，在 Apple Silicon / 8 GB Mac 上約 15～35 秒完成）：

```bash
.venv/bin/python research/robustness_check/run_robustness.py
```

```bash
.venv/bin/python research/robustness_check/run_robustness.py --quick
```

3. **執行離線單元測試與全專案測試套件**（無網路環境亦可使用小型假資料通過全部測試）：

```bash

```

## 三、哪些數值是「假設值」或「推算值」？（透明揭露）

為避免將模型假設誤認為真實成交紀錄，以下完整列出本研究中所有假設值與推算段落：

1. **第 3 關跨國價格指數之保守年化股息率假設（明確為假設值）**：
   - 日本 `^N225`：**`+1.5% / 年`**
   - 德國 `^GDAXI`：**`+2.5% / 年`**（註：`^GDAXI` 本身編製已含配息再投資，主表依研究規格統一加計 `+2.5%`，另於 `results.json` 與報告附不額外加息之對照值並記錄於 `data_issues`）
   - 英國 `^FTSE`：**`+3.5% / 年`**
   - 中國上證 `000001.SS`：**`+2.0% / 年`**
2. **ETF 上市前／Yahoo 缺漏段之回溯推算假設**：
   - `0050` 於 `1997-07-02 ～ 2009-03-09`：以 `^TWII` 日報酬外加 **`+3.0% / 年`** 估計股息殖利率推算。
   - `00631L` 於 `2015-08-25` 前：以 `2 × 0050` 含息日報酬扣除 **`1.16% / 年`** 總費用率每日重設推算。
   - `TQQQ` 於 `2010-02-11` 前：以 `3 × QQQ` 日報酬扣除 **`0.88% / 年`** 內扣費與 **`2 × ^IRX`** 融資成本推算（`1990–1999` 之 `QQQ` 以 `^NDX + 0.4%` 科技股息扣 `0.20%` 費率銜接）。
   - `TWD=X` 於 `2004-03-24` 前：固定延用最早匯率 **`32.0230`**。
3. **交易摩擦、稅率與匯率壓力測試假設**：
   - 基準交易成本：美股換匯成本 `0.1%`（第 4 關加嚴為 **`0.3%` 換匯價差**）、美股複委託手續費 `0.1%`（另測試**每筆最低手續費 `USD 15`**）、台股再平衡買進 `0.1425%`／賣出 `0.2425%`。
   - 股息稅負假設：美股 ETF 配息預扣 **`30%`**；台股第 4 關計入二代健保補充保費 **`2.11%`**（單次配息達 **`20,000` 台幣**門檻時扣繳），綜合所得稅簡化測試 **`0%`（免稅級距）** 與 **`12%` 級距** 兩種情境。
   - 匯率長期壓力測試：除實際歷史匯率外，假設台幣對美元**連續 10 年每年升值 `2%`** 與**每年貶值 `2%`**。
4. **第 5 關真人行為與第 8 關人生階段假設**：
   - 失業情境生活費（情境 C）：假設每月生活費為每月定期定額扣款額的 **`3 倍`（即每月 `30,000` 台幣，6 個月共提領 `180,000` 台幣）**。
   - 單筆分批投入閒置資金利率：分 12 / 24 個月投入期間，尚未投入之台幣現金假設停泊於年息 **`1.0%`** 活定存。
   - 退休提領期假設：60 歲起始本金 **`1,000 萬台幣`**，首年提領率 **`4%`（40 萬／年）**，之後每年提領金額隨假設通膨率 **`2.0% / 年`** 調升，測試期 **`30 年`（至 90 歲）**。
