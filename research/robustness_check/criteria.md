## 判定標準（先寫死）
每個推薦 R1–R5 在每一關都給「通過 / 有條件通過 / 不通過」：
- 排名穩定：R1 在該關所有情境的「最大後悔值」（和該情境第一名的 XIRR 差距）中位數 ≤ 3 個百分點，而且在該關排名維持前 30% → 通過；後悔值 3–5 個百分點或排名在前 50% → 有條件通過；其他 → 不通過。
- 風險上限：該推薦在該關情境中，最大回撤超過對應上限（R1 −50%、R2 −30%、R3 −60%）的機率 ≤ 10% → 通過；10–25% → 有條件通過；> 25% → 不通過。
- R4：2 倍以上組合在各關跌破 −50% 的機率仍 ≥ 50% → 結論成立。
- R5：中位數回本時間在各關的變化幅度 ≤ ±50% → 成立。
最後的總判定：所有關都通過 = 站得住；有任何一關有條件通過、但沒有不通過 = 有條件成立（要寫出條件）；任何一關不通過 = 被推翻（要寫出替代推薦）。
